## Objetivo

Nuestro cliente DH Venture Capitals ha puesto en sus manos el desarrollo de un e-commerce para poner a prueba el desempeño de nuestro equipo al trabajar con Node.js y React.

El cliente solicita que seas tu quien elija la temática del sitio y que presentes un boceto gráfico de las principales secciones a implementar, antes de comenzar con el proceso de desarrollo.

## Metodología

Cómo quizás ya lo imaginan, nuestro cliente pide que, a la hora de desarrollar, se implemente un sistema de trabajo basado en las metodologías ágiles.

El desarrollo se dividirá en iteraciones, o hablando en el lenguaje ágil: sprints. Este sprint será el primero de ocho que abarcarán la totalidad de las temáticas del contenido completo de Full Stack.

Tu rol será el de desarrollar el sitio asegurándote de que:

* Sea estéticamente agradable (UI - User Interface).
* Sea fácil de usar (UX - User Experience).
* Sea funcional y cumpla con los requisitos del cliente.
* Las entregas se cumplan en tiempo y forma.

### Temática

La temática del sitio será orientada a una empresa que bride servicios y venda productos tecnológicos para automatizaciones y control en hogares y/o edificios, lo que comunmente se llama domótica. 

Los usuarios de la web serán personas que quieran instalar estos dispositivos en sus casas y/o profesionales. Se les brindará orientaciónen el diseño, instalación y se realizará venta de productos.
